Accordion Collapsible sections — click to expand, click again to collapse

Wrap items in .accordion. Add data-single to close others when one opens. Each item needs an .accordion-header and an .accordion-content.

What is this component?
An accordion hides long content behind a clickable header. Great for FAQs, settings panels, and detail sections.
How do I add more items?
Copy the .accordion-item block and paste it inside the same .accordion wrapper. Each item is fully independent.
What does data-single do?
data-single means only one item can be open at a time — opening a new one closes the previous one automatically.
HTML + JS 
<div class="accordion" data-single>

  <div class="accordion-item">
    <div class="accordion-header">
      Section Title
      <svg data-icon="arrow-right" class="accordion-chevron"></svg>
    </div>
    <div class="accordion-content">
      Your content here.
    </div>
  </div>

  <!-- repeat .accordion-item for more sections -->

</div>

<!-- JS -->
geUIHelper.accordion('.accordion');
Tabs Switch between content panels using a tab bar

Give the .tabmenu list a data-scope matching the panel wrapper's id. Each <li> gets a data-tab matching its panel's id. Arrow keys navigate — built in.

  • Overview
  • Details
  • Settings
Overview panel

Click a tab or use ← → arrow keys. Only one panel shows at a time.

Details panel

The active tab gets a coloured underline indicator. The rest are hidden.

Settings panel

Each data-tab value must match the matching panel's id exactly.

HTML + JS 
<!-- Tab bar: data-scope = panel wrapper id -->
<ul class="tabmenu" data-scope="myContent">
  <li class="active" data-tab="tab-one">First</li>
  <li data-tab="tab-two">Second</li>
  <li data-tab="tab-three">Third</li>
</ul>

<!-- Panel wrapper: id = data-scope value -->
<div id="myContent">
  <div class="tab active tab-panels" id="tab-one">First content</div>
  <div class="tab tab-panels" id="tab-two" hidden>Second content</div>
  <div class="tab tab-panels" id="tab-three" hidden>Third content</div>
</div>

<!-- JS -->
geUIHelper.tabs('.tabmenu');
Modal Focused dialog overlay — focus trapped, Escape or backdrop to close

Place the .modal outside the app shell, just before </body>. Open it with geUIHelper.modal('open', 'myModal') — the overlay is created automatically.

HTML + JS 
<!-- Place OUTSIDE the app div, before </body> -->
<div id="myModal" class="modal" role="dialog" aria-modal="true">
  <div class="modal-head">
    <h4>Modal Title</h4>
  </div>
  <p>Your content here.</p>
  <div class="modal-foot">
    <button class="btn" id="cancelBtn">Cancel</button>
    <button class="btn btn-primary" id="confirmBtn">Confirm</button>
  </div>
</div>

<!-- JS -->
geUIHelper.modal('open',  'myModal');
geUIHelper.modal('close', 'myModal');
Toast Auto-dismissing notification messages — no HTML required

One line of JS — no HTML needed. Types: success, error, info, warning. Third argument is duration in milliseconds (default: 3000 = 3 seconds).

JS only — no HTML needed 
geUIHelper.toast('Saved successfully!', 'success');
geUIHelper.toast('Something went wrong.', 'error');
geUIHelper.toast('Here is some information.', 'info');
geUIHelper.toast('This cannot be undone.', 'warning');

// Custom duration (milliseconds):
geUIHelper.toast('Stays 5 seconds.', 'error', 5000);

HTML + JS 
<div class="dd-wrap">
  <button class="btn btn-primary dd-trigger">Open Menu</button>
  <div class="dd-menu" role="menu">
    <div class="dd-item">Option 1</div>
    <div class="dd-item">Option 2</div>
    <hr class="dd-divider">
    <div class="dd-item dd-item-danger">Delete</div>
  </div>
</div>

<!-- Right-aligned: add .dd-menu-right to the menu -->

<!-- JS — geDropdown extends geUIHelper -->
class geDropdown extends geUIHelper {
  static init(sel) {
    geUIHelper.els(sel).forEach(trigger => {
      const menu = trigger.nextElementSibling;
      geUIHelper.on(trigger, 'click', e => {
        e.stopPropagation();
        geUIHelper.els('.dd-menu.active').forEach(m => {
          if (m !== menu) geUIHelper.removeClass(m, 'active');
        });
        geUIHelper.toggleClass(menu, 'active');
      });
    });
    document.addEventListener('click', () =>
      geUIHelper.els('.dd-menu.active').forEach(m =>
        geUIHelper.removeClass(m, 'active')));
  }
}
geDropdown.init('.dd-trigger');

Context Menu Right-click menu that appears at the cursor position

Place #ctxMenu outside the app shell (it uses position: fixed). Listen for contextmenu on your target, set left/top to the cursor coords, add .active.

Right-click anywhere in this box
HTML + JS 
<!-- Target element (anything) -->
<div id="myTarget">Right-click me</div>

<!-- Menu: outside app div, position:fixed via CSS -->
<div id="myCtxMenu" class="ctx-menu" role="menu">
  <div class="ctx-item"><svg data-icon="edit"></svg> Edit</div>
  <div class="ctx-item"><svg data-icon="download"></svg> Copy</div>
  <hr class="ctx-divider">
  <div class="ctx-item ctx-item-danger"><svg data-icon="trash"></svg> Delete</div>
</div>

<!-- JS -->
const target = geUIHelper.el('#myTarget');
const menu   = geUIHelper.el('#myCtxMenu');

geUIHelper.on(target, 'contextmenu', e => {
  e.preventDefault();
  menu.style.left = e.clientX + 'px';
  menu.style.top  = e.clientY + 'px';
  geUIHelper.addClass(menu, 'active');
});

document.addEventListener('click', () =>
  geUIHelper.removeClass(menu, 'active'));

Form Validated inputs — name, email, select, textarea, submit

Wrap each label+input pair in .da-form-group. Call geUIHelper.handleForm() with an async function. Return { ok: true } to show the success toast and reset automatically.

HTML + JS 
<form id="myForm" novalidate>
  <div class="da-form-group">
    <label for="f-name">Name *</label>
    <input type="text" id="f-name" name="name" required>
  </div>
  <div class="da-form-group">
    <label for="f-email">Email *</label>
    <input type="email" id="f-email" name="email" required>
  </div>
  <button type="submit" class="btn btn-primary">Submit</button>
</form>

<!-- JS -->
const form = geUIHelper.el('#myForm');
geUIHelper.handleForm(form, async (data) => {
  console.log('Submitted:', data);
  // your save logic here…
  return { ok: true }; // success toast + form reset
});
Cards Content containers with optional header, body, and footer

A card has three optional zones: .da-card-head, .da-card-body, .da-card-foot. Add a variant class on the card itself for colour: da-card-primary, da-card-success, da-card-danger.

Default
Neutral card for general content or information blocks with no status.
Success
Use for completed items, confirmations, or positive status indicators.
Danger
Use to highlight destructive actions, errors, or critical warnings.
HTML — no JS required 
<div class="da-card">
  <div class="da-card-head">Card Title</div>
  <div class="da-card-body">Card content here.</div>
  <div class="da-card-foot">
    <button class="btn">Action</button>
  </div>
</div>

<!-- Colour variants -->
<div class="da-card da-card-success">...</div>
<div class="da-card da-card-danger">...</div>

<!-- Grid layout -->
<div class="da-cards-grid">
  <div class="da-card">...</div>
  <div class="da-card">...</div>
</div>
